# Persona 产品战略（2026-07-30 收敛）

> 这份文档是一次**定位收敛**的产物，不是功能路线图。它由一轮"该不该继续加功能"的诚实复盘得出，结论是：**近期一个功能都不加，把力气全部转向内容质量、发现性、信任与被找到。**

## 1. 定位（北极星，一句话）

**Persona = 一键把"有目的的人设"套到你已经在用的免费网页大模型（DeepSeek / Claude / ChatGPT）上，零成本解决大部分常见需求。**

它**是什么**：一个好用、可爱、可信、能被搜到的免费小工具；一个"广播型"引流入口（见 §5）。

它**不是什么**：
- 不是简化版酒馆 / roleplay 平台——那是全成本、全责任的生意，会把我们的优势整个倒过来（见 §2），不是小团队该碰的。
- 不是 agent——不做 MCP / 工具调用 / API。那需要花钱、是专业 agent 的事；**大部分常见需求，一个好人设 + 免费网页对话就够了。**
- 不是深度情感陪伴——那是付费产品最强、我们最弱、且踩 CWS 2026 红线的区。

**真实用例锚点**（用户本人的需求，用作验收清单）：扮老板（练谈判）、扮招聘者（练面试）、扮想约会的对象（练一次告白/约会，**一次性演练，不做深度陪伴**）、调研某只股票、研究某个领域。共同点：**都是有目的、几轮到几十轮就结束的会话**——天然绕开"长对话忘设定"这个死结。

### 1.1 统一客群洞察：接住"轻到不值得付费"的需求，不是抢红海市场（2026-07-31 修正）

**我们不是在和 character.ai / Talkie AI 这类完备的付费角色聊天平台竞争。** 那些是要转化订阅的商业化平台，天然筛掉了"偶尔想聊聊"的轻量用户——为了偶尔跟一个 MBTI 人格聊两句、或者探索一下自己的星座，去下载 App、办年费会员，这笔 ROI 谁都算不过来。**这批被红海平台筛掉、赚不到钱的人，才是我们的目标用户。**

这条洞察把"实用人设"（练谈判/面试）和"娱乐人设"（MBTI/星座/原创角色原型）统一到同一条逻辑下，不是两个方向：

> **只要一个需求足够轻/足够偶发，不值得用户为它专门下载 / 付费 / 注册，我们的"免费网页对话 + 一键人设"就是最优解——不管这个需求是"练一次谈薪"还是"聊两句我的星座"。**

**How to apply**：评估任何新人设方向时，别问"这个赛道谁在做、我们打不打得过"，要问"这个需求轻到什么程度，值不值得用户专门下载/付费——如果不值得，我们零成本、零下载的形态就是天然合适的接盘者"。同理，别因为"这个类目已经很卷"（如 MBTI 在 character.ai 上一大把）就判它不值得做——**卷的是"深度角色聊天"这个商业化场景，不是"免费轻量一键探索"这个场景，两者客群不重叠。**

## 2. 为什么这么定（诚实的推理链）

- **没有技术壁垒**，也不装有。PE 能从 Reddit 复制改写，注入机制不新，整个东西几周能被抄。承认这点。
- **我们做的是"别人看不上的市场"**——这是能赢的打法，但赢的方式不是技术，是**别人不愿意干的脏活累活**（见 §3）。
- **平台会倒转我们的优势**：我们现在靠"零成本 + 零责任"活着；自营 roleplay 平台是"全成本（算力）+ 全责任（审核/T&S/版权/未成年人）"，把命根子倒过来。所以不碰。
- **引流是"广播型"不是"捕获型"**：我们守的"零网络 / 零账号 / 零遥测"纯净架构，天生抓不住、也测不到人。所以漏斗只能靠**品牌 + 扩展自身的更新/公告通道**触达已安装用户；**不为一个 someday-maybe 的平台，现在就往架构里加网络/账号**——那会污染信任与过审这块最硬的招牌。

## 3. 护城河（无技术壁垒市场里唯一持久的东西）

不是任何功能或点子，是**比对手更能忍受做琐碎而正确的事**：

1. **策展深度**：抄 10 个 prompt 容易；抄不走的是一个持续维护、双语、按真实用途组织、逐个真机验过的人设库。
2. **发现性**：让人 10 秒从 100+ 里找到对的那个——把"一堆 prompt"变成"一个产品"的关键。
3. **信任 / 合规**：零权限、零网络、不碰擦边。CWS 2026 新政会批量清掉做 NSFW/越狱的同类——**竞品自己会死一批，我们靠干净活下来。**
4. **品味 / 打磨**：别人甩一堆 prompt 就完事，我们把浮动按钮怎么不挡输入框都磨到位。

## 4. 冻结清单（明确不做，防止"强行做无用的东西"）

- ❄️ **长对话记忆整条线冻结**：保留最简单的手动 📌（低摩擦、清楚有用）；🧠 自摘要那套**不当卖点推、不再投入**——它服务的是一个连用户本人都没有的需求（有目的的短会话不吃这个）。
- ❄️ **不加新功能**，除非验证信号（§6）明确要求。
- ❄️ 不做 agent / MCP / 工具 / API。
- ❄️ 不加网络 / 账号 / 遥测。
- ❄️ 不做 roleplay 平台的任何前置工作。

## 5. 近期工作流（全部是内容 / 发现 / 信任，不是功能）

**A. 人设质量：对得起真实用途**（第一优先，见 §7）
- 拿 §1 的真实用例当验收清单，逐个真机跑，诚实判断：现有库里有没有对应的好人设？扮得够不够用？
- **把任务型人设从"静态角色卡"改成"开场先反问 2-3 个关键上下文"**（老板在哪家公司、谈什么岗；研究哪只股票）——一个会问清情况的人设，比自说自话的强十倍。零新机器，纯 prompt 设计。
- 内容来源纪律（复制改写 Reddit 等）：**originalize + 本地化 + 按"活儿"组织 + 质量过一遍 + 守内容红线**（禁 NSFW / 在世真人 / 具名版权角色 / 教唆暴力）。别原样搬。

**B. 发现性：10 秒找到对的人设**
- 人设库按**用户脑子里的"活儿"/场景**组织（"练一次…" / "调研…" / "扮演…"），不是按 vibe 堆。
- 面内发现：搜索、场景化入口、更说人话的命名。

**C. 被找到：CWS 发现性 = 漏斗顶端**
- 商店列表标题/描述/关键词按人真会搜的词调（"persona for ChatGPT"、"AI 面试练习"、"roleplay DeepSeek"…）；截图展示真实价值；经营评价。
- **没人搜到就没有漏斗**——这是漏斗的顶，不是收尾。

**D. 抗风险 + 信任（护城河的日常维护）**
- 平台依赖是真正的命门：DOM 变了改 adapter（selector 兜底、不改算法）；注入失败要优雅降级（现有 clipboard fallback / "请刷新"横幅）。
- 死守零权限/零网络/不擦边——这是护城河，也是未来广播型漏斗的信誉基础。
- "Persona"品牌一致性 = 未来的广播喇叭。

## 6. 验证信号（最便宜、最诚实）

无埋点，纯自省。用户（+ 几个朋友）真用一阵，只盯一件事：

> **你主动点得最多的是哪个按钮——是"应用人设"，还是 Enrich / 记忆？**

- 若几乎只点"应用" → 证实"一键启动器"是核心，Enrich/记忆继续冻结甚至简化。
- 若真的常点 Enrich/记忆 → 说明长会话场景比预想的重要，再解冻讨论。

这个答案也直接决定"roleplay vs 生产力"的重心。**在拿到信号前，按 §1 的定位走。**

## 7. 排序：第一步

**Workstream A 的试点——对 §1 那 5 个真实用例做一次"人设对得起用途"的质量审计。**
- 真机各跑一遍，产出一份诚实评估：哪些够用、哪些要重写成"会反问上下文"的写法、有没有缺口要补。
- 产出物大概率是"改 5-10 个人设的 prompt"，而不是"加一个功能"——这才是这个方向该有的样子。
- 这一步同时是**内容**（改好人设）和**验证**（看现状到底行不行），一举两得，且无论漏斗还是工具都对。
